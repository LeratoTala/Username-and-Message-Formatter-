# Student Info Formatter

A simple Python script that collects personal information from the user and displays it in a formatted profile card.

## What it does

- Prompts the user for their first name, surname, age, and favourite number
- Demonstrates all four core Python data types: `str`, `int`, `float`, and `bool`
- Performs string manipulation (uppercase, title case) and basic arithmetic
- Displays a neatly formatted profile card with the results

## Usage

```bash
python string_formatter.py
```

You'll be prompted to enter:
- First name
- Surname
- Age
- Favourite number

## Example output

```
========================================
Welcome, Jane Doe!
========================================
Full Name (UPPERCASE): JANE DOE
Full Name (Title Case): Jane Doe
Age: 20 years old
Age in Months: 240 months
Favourite Number (rounded to 2 d.p.): 3.14
Is Adult (18+): True
========================================

Data Types:
first_name -> <class 'str'>
surname -> <class 'str'>
age -> <class 'int'>
favourite_number -> <class 'float'>
is_adult -> <class 'bool'>
```

## Requirements

Python 3.x — no external dependencies.
